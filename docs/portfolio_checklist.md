- Mostrar estrutura do projeto
- Explicar a fonte de dados CCCV
- Explicar arquitetura Medallion
- Mostrar Docker Compose

## Pontos fortes

- Projeto local completo de engenharia de dados

- Uso de Airflow
- Uso de dbt
- Testes automatizados
- CI com GitHub Actions

- Alertas no Airflow
- dbt docs publicado
